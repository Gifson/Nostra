# Nostra E-Commerce Website

## Files

- `index.html` – Home Page
- `collections.html` – Collections Page
- `contact.html` – Contact Us Page
- `style.css` – Styling shared by all pages
- `script.js` – JavaScript functionality including mobile menu, hero slider, search, filters, sorting, wishlist and forms

## How to run

1. Keep all five files in the same folder.
2. Open `index.html` in a browser.
3. In VS Code, Live Server can be used for easier development.

## Collections page

The Collections page includes:
- Product search
- Occasion filters: Summer, Party, Beach
- Color filters: Red, Blue, White, Green
- Price sorting
- Name sorting
- Responsive product grid

## New Arrivals horizontal scrolling

The Home page New Arrivals and Most Wanted sections are horizontal carousels. Users can click the left/right arrows or swipe/scroll horizontally on touch devices and desktops.
